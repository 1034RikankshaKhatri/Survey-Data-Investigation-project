# Survey Data Investigation

## Project Overview

This project analyzes the Stack Overflow Annual Developer Survey 2024 dataset.

The project focuses on understanding salary, professional experience, remote work, job satisfaction, and other patterns among technology professionals.

## Objectives

- Clean and prepare the survey data.
- Analyze salary and professional experience.
- Analyze remote work patterns.
- Study job satisfaction.
- Perform SQL-based analysis.
- Create data visualizations.
- Calculate a 95% confidence interval for average yearly salary.

## Tools and Technologies

- Python
- Pandas
- NumPy
- SQLite
- Matplotlib
- SciPy
- Google Colab

## Project Files

- `Survey_Data_Investigation.ipynb` – Complete project notebook
- `Survey_Data_Investigation_Report.docx` – Project report

## Dataset

Stack Overflow Annual Developer Survey 2024.

## Conclusion

The project demonstrates how Python, SQL, data visualization, and statistical analysis can be used to analyze a real-world survey dataset.
